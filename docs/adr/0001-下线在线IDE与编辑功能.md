# 0001 下线在线 IDE 与内容/动画编辑功能

- 状态：已采纳
- 日期：2026-11-25
- 关联提交：`revert-ide-editors` 分支上的单次回滚提交

## 背景

浏览器内的编辑能力（Markdown 写作、C# 示例、`.anim.ts` 动画编辑、统一提交）全部由 `tml-ide-app`
构建成 `/tml-ide/`，站点导航直接进入这个应用；`site/index.html` 等 8 个页面的主导航挂着「在线 IDE」入口，
`site/content/如何贡献/` 下的多篇文章也以它为主线。真正属于站点自己的页面（`shader-playground`、
`article-studio`、`shader-gallery`、`shader-contribute`）在「下线旧IDE页面」（78008e4）里被改成跳转壳并删除。

结果是：站点阅读能力与编辑能力耦合成一个仓库、一条构建链，删除其中任何一半都需要同时处理引用。

## 决策

1. 删除 `tml-ide/` 与 `tml-ide-app/`，并同步断开构建链（`package.json`、`pnpm-workspace.yaml`、`deploy.yml`、`tmp-playwright` 验收脚本）。
2. 下线内容编辑与动画编辑：移除站点的 IDE 导航、写作手册与 `.anim.ts` 编辑指引；贡献流程改为「在仓库里改 Markdown → 提 PR」。
3. 保留在线 Shader：从提交 1540863 恢复 `site/pages/shader-playground.html` 及其依赖的 7 个 JS、2 个 CSS，
   并把 `viewer.html`、`anim-renderer.html` 的适配器引用改到 `site/assets/js/`。
4. 保留动画渲染：`site/pages/anim-renderer.html` 原样保留，不新增编辑能力。
5. 一并下线 `fun-test/`、`limbus/` 两个独立页；根 `index.html` 改为跳转 `/site/`。

## 备选方案与取舍

- 整树回退到 2026-02 的提交：能直接得到旧站点，但会丢掉 2 月之后所有教程内容更新，代价高于收益。
- 只删导航入口、保留 `tml-ide-app`：入口删了但构建链、测试与 CI 仍要维护一个没有用户的工程。
- 保留 IDE、仅删除页面内的编辑按钮：改动面更大，且与「不再提供浏览器内写作」的目标矛盾。

## 后果

- 站点不再提供任何浏览器内写作/编辑入口；贡献者需要 GitHub 账号并能操作 PR。
- `shader-playground` 回退到 2026-02 的版本，后续对它的改动需要另开分支维护。
- 需要回归编辑能力时，必须重新引入独立工程，而不是在站点里加按钮。
- 历史仍在 `main`：需要复原时可从 `b7ccb04` 取回，但成本高于一次 `git revert`。
