# 前言

在泰拉瑞亚中，你一定用过工作台合成木板、用熔炉把矿石炼成锭。

这就是合成表（Recipe）系统的作用！

{color:Mad}{在这一章，你将学会如何创建自己的合成配方！}

合成表让你的 Mod 更加完整：
- 让自制物品可以被制作
- 定义材料和工作站需求
- 创建复杂的材料链

# 创建第一个合成配方

## ModSystem 类

合成配方需要放在 `ModSystem` 的子类中。`ModSystem` 是游戏系统的基类，在游戏加载时会自动调用配方相关方法。

## AddRecipes 方法

`AddRecipes` 是添加配方的入口方法。

### 链式调用风格

现代写法使用链式调用，代码简洁易读：
- `Recipe.Create()` 创建配方，指定结果物品和数量
- `AddIngredient()` 添加一个材料需求
- `AddTile()` 添加工作站需求
- `Register()` 注册配方（必须调用）

> [!IMPORTANT] Register() 必须调用
>
> 没有调用 `Register()` 的配方不会生效！

# 常用工作站

工作站是玩家必须在附近才能合成的设施：

| TileID | 名称 | 用途 |
|--------|------|------|
| `TileID.WorkBenches` | 工作台 | 基本合成 |
| `TileID.Furnaces` | 熔炉 | 矿石冶炼 |
| `TileID.Anvils` | 砧 | 金属加工 |
| `TileID.Cauldrons` | 炼药桌 | 药水制作 |
| `TileID.HeavyWorkBench` | 重型工作台 | 高级合成 |
| `TileID.CrystalBall` | 水晶球 | 魔力相关 |

# 合成组（RecipeGroup）

## 什么是合成组

合成组允许多种物品作为同一个材料槽的输入。

例如：`RecipeGroupID.Wood` 包含所有木头变体（橡木、红木、棕榈木……）。

使用合成组可以让配方更灵活，玩家可以用任意木头来制作。

## 常用合成组

| 合成组 ID | 包含物品 |
|-----------|----------|
| `RecipeGroupID.Wood` | 所有木头 |
| `RecipeGroupID.IronBar` | 铁锭、铅锭 |
| `RecipeGroupID.SilverBar` | 银锭、钨锭 |
| `RecipeGroupID.GoldBar` | 金锭、铂金锭 |
| `RecipeGroupID.Dirt` | 所有泥土 |

## 创建自定义合成组

使用 `AddRecipeGroups` 注册自定义合成组。`new RecipeGroup()` 构造函数第一个参数是显示名称回调，其余参数是可选的物品 ID 列表。

`RegisterGroup()` 注册合成组，建议使用 `ModName:GroupName` 格式命名。

# 完整示例

一个完整的配方系统包含 `AddRecipes` 和 `AddRecipeGroups` 两个方法。

`AddRecipes` 中使用 `Recipe.Create()` 链式调用创建配方，使用 `AddRecipeGroup()` 添加合成组需求。

`AddRecipeGroups` 中使用 `RecipeGroup.RegisterGroup()` 注册自定义合成组。
