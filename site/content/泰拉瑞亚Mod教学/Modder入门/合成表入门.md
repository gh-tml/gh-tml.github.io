# 前言

在泰拉瑞亚中，你一定用过工作台合成木板、用熔炉把矿石炼成锭。

这就是合成表（Recipe）系统的作用！

{color:Mad}{在这一章，你将学会如何创建自己的合成配方！}

合成表让你的 Mod 更加完整：
- 让自制物品可以被制作
- 定义材料和工作站需求
- 创建复杂的材料链

# 创建第一个合成配方

## ModSystem 类

合成配方需要放在 `ModSystem` 的子类中：

[FirstRecipe 类定义](cs:./code/firstrecipe.cs#cs:t:ModDocProject.ModsSource.Modder入门.FirstRecipe)

`ModSystem` 是游戏系统的基类，在游戏加载时会自动调用配方相关方法。

## AddRecipes 方法

`AddRecipes` 是添加配方的入口：

[AddRecipes 方法](cs:./code/firstrecipe.cs#cs:m:ModDocProject.ModsSource.Modder入门.FirstRecipe.AddRecipes())

### 链式调用风格

现代写法使用链式调用，代码简洁易读：

[炼铁配方](cs:./code/firstrecipe.cs#cs:m:ModDocProject.ModsSource.Modder入门.FirstRecipe.AddRecipes())

```csharp
Recipe.Create(ItemID.IronBar, 5)
    .AddIngredient(ItemID.IronOre, 10)
    .AddTile(TileID.Furnaces)
    .Register();
```

### 方法解析

| 方法 | 作用 | 示例 |
|------|------|------|
| `Recipe.Create()` | 创建配方，指定结果物品和数量 | `Recipe.Create(ItemID.IronBar, 5)` |
| `AddIngredient()` | 添加一个材料需求 | `.AddIngredient(ItemID.IronOre, 10)` |
| `AddTile()` | 添加工作站需求 | `.AddTile(TileID.Furnaces)` |
| `Register()` | 注册配方（必须调用） | `.Register()` |

> [!IMPORTANT] Register() 必须调用
>
> 没有调用 `Register()` 的配方不会生效！

# 常用工作站

工作站是玩家必须在附近才能合成的设施：

| TileID | 名称 | 用途 |
|--------|------|------|
| `TileID.WorkBenches` | 工作台 | 基本合成 |
| `TileID.Furnaces` | 熔炉 | 矿石冶炼 |
| `TileID.Anvils` | 砧 | 金属加工 |
| `TileID.Cauldrons` | 炼药桌 | 药水制作 |
| `TileID.HeavyWorkBench` | 重型工作台 | 高级合成 |
| `TileID.CrystalBall` | 水晶球 | 魔力相关 |

# 合成组（RecipeGroup）

## 什么是合成组

合成组允许多种物品作为同一个材料槽的输入。

例如：`RecipeGroupID.Wood` 包含所有木头变体（橡木、红木、棕榈木……）。

使用合成组可以让配方更灵活：

```csharp
Recipe.Create(ItemID.Wood, 20)
    .AddRecipeGroup(RecipeGroupID.Wood)  // 任意木头都行
    .AddTile(TileID.WorkBenches)
    .Register();
```

## 常用合成组

| 合成组 ID | 包含物品 |
|-----------|----------|
| `RecipeGroupID.Wood` | 所有木头 |
| `RecipeGroupID.IronBar` | 铁锭、铅锭 |
| `RecipeGroupID.SilverBar` | 银锭、钨锭 |
| `RecipeGroupID.GoldBar` | 金锭、铂金锭 |
| `RecipeGroupID.Dirt` | 所有泥土 |

## 创建自定义合成组

使用 `AddRecipeGroups` 注册自定义合成组：

[AddRecipeGroups 方法](cs:./code/firstrecipe.cs#cs:m:ModDocProject.ModsSource.Modder入门.FirstRecipe.AddRecipeGroups())

```csharp
RecipeGroup SilverBarRecipeGroup = new RecipeGroup(
    () => $"{Lang.GetItemNameValue(ItemID.SilverBar)} 或 {Lang.GetItemNameValue(ItemID.TungstenBar)}",
    ItemID.SilverBar,
    ItemID.TungstenBar
);

RecipeGroup.RegisterGroup("SilverBarGroup", SilverBarRecipeGroup);
```

> [!TIP] 命名规范
>
> 建议使用 `ModName:GroupName` 格式命名，便于区分不同 Mod 的合成组。

# 完整示例

一个完整的配方系统示例：

```csharp
public class ExampleRecipes : ModSystem
{
    public override void AddRecipes()
    {
        // 简单配方
        Recipe.Create(ItemID.IronBar, 5)
            .AddIngredient(ItemID.IronOre, 10)
            .AddTile(TileID.Furnaces)
            .Register();

        // 使用合成组
        Recipe.Create(ItemID.Wood, 20)
            .AddRecipeGroup(RecipeGroupID.Wood)
            .AddTile(TileID.WorkBenches)
            .Register();
    }

    public override void AddRecipeGroups()
    {
        // 注册自定义合成组
        RecipeGroup.RegisterGroup("ExampleMod:CustomGroup", customGroup);
    }
}
```
