## 物块 vs 物品：有什么区别？

| 概念 | 说明 |
|------|------|
| 物块 (Tile) | 放置在世界中的方块，如石头、木材、矿石 |
| 物品 (Item) | 玩家背包中的东西，可以拿在手上或放置 |

一个物块通常需要配套的物品来放置。

# 创建一个基础物块

## 物块类定义

物块通过继承 `ModTile` 来创建：

[物块类](cs:./code/firsttile_block.cs#cs:t:ModDocProject.ModsSource.Modder入门.FirstBlock)

### 核心属性

```csharp
Main.tileSolid[Type] = true;      // 物块是实心的
Main.tileBlockLight[Type] = true; // 阻挡光线
Main.tileMergeDirt[Type] = true;  // 与泥土合并
```

> [!NOTE] 实心 vs 非实心
>
> - **实心物块**：玩家不能穿过，需要镐子挖掘
>
> - **非实心物块**：玩家可以直接穿过（如草、花）

### 尘埃和音效

```csharp
DustType = DustID.Platinum;  // 挖掘产生的尘埃类型
HitSound = SoundID.Tink;    // 挖掘时播放的声音
```

> [!TIP] 尘埃类型参考
>
> - `DustID.Platinum` - 铂金色
> - `DustID.Gold` - 金色
> - `DustID.Dirt` - 泥土色
> - `ModContent.DustType<Sparkle>()` - 自定义尘埃

### 地图显示

```csharp
AddMapEntry(new Color(200, 200, 200));
```

这决定了物块在地图上显示的颜色和名称！

## 挖掘尘埃数量

[尘埃效果](cs:./code/firsttile_block.cs#cs:m:ModDocProject.ModsSource.Modder入门.FirstBlock.NumDust(int,int,bool,ref int))

```csharp
num = fail ? 1 : 3;
```

当 `fail = true`（镐子威力不足）时，只产生1个尘埃；正常时产生3个。

# 创建一个矿石

矿石是特殊的物块，有一些额外的属性让它们更容易被找到：

[矿石物块](cs:./code/firsttile_ore.cs#cs:t:ModDocProject.ModsSource.Modder入门.FirstOre)

### 矿石特殊属性

```csharp
TileID.Sets.Ore[Type] = true;           // 标记为矿石
Main.tileSpelunker[Type] = true;         // 洞穴探险药水高亮
Main.tileOreFinderPriority[Type] = 410;  // 矿石探测器优先级
Main.tileShine2[Type] = true;           // 光源下闪烁
Main.tileShine[Type] = 975;             // 尘埃出现频率
```

> [!IMPORTANT] Spelunker 高亮
>
> `tileSpelunker = true` 让玩家用洞穴探险药水时能看到你的矿石
>
> **强烈建议所有矿石都设置这个！**

### 矿石探测器优先级参考

| 矿石 | 优先级 |
|------|--------|
| 铁 | 410 |
| 金 | 500 |
| 铂金 | 600 |
| 钛金 | 700 |

### 生物群落 Sight

[生物群落Sight](cs:./code/firsttile_ore.cs#cs:m:ModDocProject.ModsSource.Modder入门.FirstOre.IsTileBiomeSightable(int,int,ref Color))

这让某些特殊药水也能探测到你的矿石！

# 创建一个家具

家具物块需要更多的设置，包括尺寸和合成表关联：

[家具物块](cs:./code/firsttile_furniture.cs#cs:t:ModDocProject.ModsSource.Modder入门.FirstWorkbench)

### 家具关键属性

```csharp
Main.tileTable[Type] = true;       // 标记为桌子类
Main.tileSolidTop[Type] = true;    // 顶部可放置物品
Main.tileFrameImportant[Type] = true;  // 有多帧动画
TileID.Sets.DisableSmartCursor[Type] = true;  // 禁用智能光标
```

### 尺寸设置

```csharp
TileObjectData.newTile.CopyFrom(TileObjectData.Style2x1);
TileObjectData.newTile.CoordinateHeights = [18];
TileObjectData.addTile(Type);
```

> [!NOTE] Style 参考
>
> - `Style2x1` - 2格宽1格高（如工作台、椅子）
>
> - `Style1x1` - 1格大小（如旗帜）
>
> - `Style2x2` - 2格大小（如箱子、熔炉）

### 合成表关联

```csharp
AdjTiles = [TileID.WorkBenches];
```

这让你的家具可以被用作合成站！玩家可以在它旁边合成物品。

### 房间需求

```csharp
AddToArray(ref TileID.Sets.RoomNeeds.CountsAsTable);
```

这让NPC认为这个家具可以用于住房！

# 物块对应的物品

```csharp
Item.DefaultToPlaceableTile(ModContent.TileType<FirstBlock>());
```

这行代码自动设置了放置物块所需的所有属性！
