# 为什么本地化是主线能力

文本硬编码会让后续章节越来越难维护。把本地化放在主线里，能提前建立“逻辑和文案分离”的习惯。

- [ExampleHelmet 中的 LocalizedText 用法](cs:./code/armor_examplehelmet.cs)
- [ExampleRecipes 中的语言键调用](cs:./code/project_examplerecipes.cs)
- [本地化官方来源清单](cs:./code/localization_examplemod_manifest.md)

上面的第三个文件记录了 stable 分支对应的 `Localization/en-US.hjson` 与 `Localization/zh-Hans.hjson` 官方来源，便于审计。

# C# mini-lesson

本地化里最重要的不是“写字符串”，而是把文本当成键值资源。C# 侧只保留键和参数，不拼接最终文案。

# 不要硬编码文本

把显示文本直接写进逻辑代码，会让多语言、改文案、统一审查都变得困难。按键名组织内容，后续章节复用会更轻松。
