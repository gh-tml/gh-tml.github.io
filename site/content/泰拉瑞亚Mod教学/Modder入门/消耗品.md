# 前言

> [!WARNING] 来自冒险家的提醒:
>
> ***珍惜你背包里的每一瓶药水***
>
> ***因为你永远不知道下一秒会遇见什么***

{color:Mad}{消耗品——用过就没了！}

在泰拉瑞亚中，消耗品是一类特殊的物品。使用后会被消耗（减少数量），包括：

| 类型 | 例子 | 特点 |
|------|------|------|
| Buff药水 | 恢复药水、增益药水 | 喝下去给予Buff |
| 食物 | 苹果派、南瓜派 | 给予饱食Buff和额外效果 |
| 钓鱼箱 | 各种宝匣 | 右键打开获得物品 |

{color:Mad}{学会创建消耗品，你的Mod将更加完整！}

## 消耗品的关键属性

```csharp
Item.consumable = true;     // 标记为可消耗
Item.maxStack = 999;        // 最大堆叠数量
```

# 创建一个Buff药水

Buff药水是我们之前学过的内容——创建一个物品，设置 `buffType` 和 `buffTime`：

[Buff药水](cs:./code/firstconsumable_potion.cs#cs:t:ModDocProject.ModsSource.Modder入门.FirstPotion)

### 关键属性

```csharp
Item.useStyle = ItemUseStyleID.DrinkLiquid;  // 喝药水的动画
Item.buffType = ModContent.BuffType<FirstDefenseBuff>();  // 给予的Buff
Item.buffTime = 5400;  // Buff持续时间（帧）
```

> [!TIP] 喝药水动画
>
> `ItemUseStyleID.DrinkLiquid` 会让玩家做出喝药水的动作
>
> 必须配合 `DrinkParticleColors` 才能有粒子效果！

### 粒子颜色

```csharp
ItemID.Sets.DrinkParticleColors[Type] =
[
    new Color(240, 240, 240),
    new Color(200, 200, 200),
    new Color(140, 140, 140)
];
```

这些颜色决定了喝药水时飞出的粒子颜色！

# 创建一个食物

食物有特殊的动画和机制：

[食物物品](cs:./code/firstconsumable_food.cs#cs:t:ModDocProject.ModsSource.Modder入门.FirstFood)

### 食物特殊设置

```csharp
// 注册食物动画（3帧）
Main.RegisterItemAnimation(Type, new DrawAnimationVertical(int.MaxValue, 3));

// 食物粒子颜色
ItemID.Sets.FoodParticleColors[Type] = [...];

// 标记为食物
ItemID.Sets.IsFood[Type] = true;
```

### DefaultToFood

```csharp
Item.DefaultToFood(22, 22, BuffID.WellFed3, 57600);
```

> [!NOTE] DefaultToFood 参数
>
> `DefaultToFood(宽度, 高度, 主Buff类型, Buff持续时间)`
>
> 这个方法自动设置了食物需要的所有基本属性！

### 进食额外效果

[食物消耗特效](cs:./code/firstconsumable_food.cs#cs:m:ModDocProject.ModsSource.Modder入门.FirstFood.OnConsumeItem(Player))

```csharp
public override void OnConsumeItem(Player player)
{
    player.AddBuff(BuffID.SugarRush, 3600);
}
```

`OnConsumeItem` 在食物被吃下后触发，可以添加额外的Buff！

# 创建一个钓鱼箱

钓鱼箱是一种特殊的消耗品——右键打开可以获得各种物品：

[钓鱼箱物品](cs:./code/firstconsumable_crate.cs#cs:t:ModDocProject.ModsSource.Modder入门.FirstCrate)

### 钓鱼箱标记

```csharp
ItemID.Sets.IsFishingCrate[Type] = true;
```

> [!IMPORTANT] 这个很重要！
>
> 只有设置了这个，钓鱼时才有几率钓到这个箱子！

### 放置为物块

```csharp
Item.DefaultToPlaceableTile(ModContent.TileType<FirstCrateTile>());
```

钓鱼箱放置后会变成一个可以右键打开的物块。

### 右键使用机制

[右键打开箱子](cs:./code/firstconsumable_crate.cs#cs:m:ModDocProject.ModsSource.Modder入门.FirstCrate.CanRightClick())

```csharp
public override bool CanRightClick()
{
    return true;
}
```

返回 `true` 后，物品会在右键时被消耗并调用 `ModifyItemLoot`。

### 掉落物规则

[掉落物规则](cs:./code/firstconsumable_crate.cs#cs:m:ModDocProject.ModsSource.Modder入门.FirstCrate.ModifyItemLoot(ItemLoot))

掉落规则有很多种类型：

| 规则 | 说明 | 示例 |
|------|------|------|
| `Common` | 固定掉落 | 必定掉落10个金币 |
| `OneFromOptions` | 从选项中选一个 | 从药水A、B、C中随机一个 |
| `OneFromRules` | 按几率掉落 | 每7次有1次掉落 |

> [!NOTE] 规则嵌套
>
> 可以用 `OneFromRules` 从多个 `Common` 规则中选择！
>
> 这就是为什么钓鱼箱能同时掉落矿石、药水和金币！

### 示例：矿石掉落

```csharp
IItemDropRule[] oreTypes =
[
    ItemDropRule.Common(ItemID.CopperOre, 1, 30, 50),
    ItemDropRule.Common(ItemID.IronOre, 1, 30, 50),
    ItemDropRule.Common(ItemID.SilverOre, 1, 30, 50),
];

itemLoot.Add(new OneFromRulesRule(7, oreTypes));
```

这表示：每7次尝试，有1次随机掉落一种矿石，每次掉落30-50个。

```quiz

id: quiz-consume-1
question: |
  `Item.maxStack = Item.CommonMaxStack` 的值是9999。

  大多数物品的最大堆叠数确实是9999。
```

```quiz

id: quiz-consume-2
question: |
  如果想让玩家钓鱼时有几率获得箱子，需要设置什么？
options:
  - id: A
    text: Item.IsCrate = true
  - id: B
    text: ItemID.Sets.IsFishingCrate[Type] = true
  - id: C
    text: CanFishCrate = true
answer: B
explain: |
  正确答案是 B。
  `ItemID.Sets.IsFishingCrate[Type] = true` 标记这个物品为钓鱼箱！
```

```quiz
type: single
id: quiz-consume-3
question: |
  `OneFromRulesRule(7, options)` 是什么意思？
options:
  - id: A
    text: 必定掉落，会掉落7次
  - id: B
    text: 每7次有1次机会随机掉落一个
  - id: C
    text: 每次掉落7个
answer: B
explain: |
  第一个参数是几率的倒数。
  7表示"每7次有1次"，而不是"掉落7个"！
```
