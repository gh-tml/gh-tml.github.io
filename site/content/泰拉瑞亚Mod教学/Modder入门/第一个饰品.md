# 核心

```csharp
public override void SetDefaults()
{
    Item.accessory = true; // 判定物品为饰品
}
```
## 1.饰品效果

```csharp
public override void UpdateAccessory(Player player, bool hideVisual)
{      
    // 这里写饰品的效果
}
```

## 2.一些常见的效果

```csharp
public override void UpdateAccessory(Player player, bool hideVisual)
{      
    player.moveSpeed += 1.2f; // 增加移动速度
    player.noFallDmg = true; // 免疫掉落伤害
    player.lavaImmune = true; // 免疫岩浆伤害
    player.GetDamage(DamageClass.Generic) += 0.15f; // 增加伤害（换成你想要的伤害）  
    player.GetCritChance(DamageClass.Generic) += 5; // 增加暴击（换成你想要的伤害）
    player.manaCost -= 0.2f;               // 魔力消耗
    player.statManaMax2 += 20;             // 最大魔力（可以换成Life）    
}
```
如果你想使用原版的效果，请查询源代码中的`Player.cs`，里面搜索对应的`bool`。
你应该学会查看源代码（虽然是一坨，但是有时候还是得看）。

## 3.在Player里面写效果
如果你不想在ModItem里面写饰品的效果，想更方便的管理效果，你可以创建一个`ModPlayer`把所有的效果都写在这里面。

```csharp
// 继承ModPlayer
public class AccessoriesPlayer : ModPlayer
{
    public bool ExampleEffect; // 创建一个bool值来记录你的饰品的状态

    // 每帧重置所有效果，防止摘下饰品后效果还在
    public override void ResetEffects()
    {
        ExampleEffect = false;
    }

    //玩家死亡时清除所有效果
    public override void UpdateDead()
    {
        ExampleEffect = false;
    }
 
    // 这里可以写持续的效果
    public override void PostUpdate()
    {
        // 判定你的bool
        if(ExampleEffect)
        {
          // 在这里写你的效果
        }
    }
}
```
在写完这个之后，在你的物品中的`UpdateAccessory`添加刚才写的效果
```csharp
player.GetModPlayer<AccessoriesPlayer>().ExampleEffect = true;
```
这样你的饰品就可以有效果了
