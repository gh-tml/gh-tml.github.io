# 前言

在泰拉瑞亚中，你一定用过星尘法杖召唤星尘之龙、用矮人法杖召唤小鬼……

这些跟随玩家、自动攻击敌人的存在叫做**召唤物（Minion）**！

{color:Mad}{在这一章，你将学会如何创建属于自己的召唤物！}

召唤物系统包含三个部分：
- `ModBuff` - 控制召唤物的存在状态
- `ModItem` - 作为召唤媒介的物品
- `ModProjectile` - 召唤物的本体

# 召唤物的组成部分

## 三者关系

```
玩家使用召唤物品
    ↓
添加 Buff
    ↓
触发投射物生成 → 召唤物出现
```

当玩家使用召唤物品时：消耗魔力、给予玩家一个 Buff、Buff 触发投射物生成，投射物就是召唤物本体。

# 创建召唤物Buff

## FirstMinionBuff 类

`ModBuff` 子类控制召唤物在玩家身上的显示状态。

[FirstMinionBuff 类定义](cs:./code/firstminion.cs#cs:t:ModDocProject.ModsSource.Modder入门.FirstMinionBuff)

### SetStaticDefaults

`Main.buffNoSave[Type] = true` 表示这个 Buff 不会在玩家退出世界时保存。

`Main.buffNoTimeDisplay[Type] = true` 表示不在 Buff 栏显示剩余时间。

### Update 方法

在 `Update` 方法中使用 `player.ownedProjectileCounts[]` 检测召唤物是否存在。如果存在则刷新时间，如果不存在则移除 Buff。

# 创建召唤物品

## FirstMinionItem 类

`ModItem` 子类作为召唤媒介的物品。

[FirstMinionItem 类定义](cs:./code/firstminion.cs#cs:t:ModDocProject.ModsSource.Modder入门.FirstMinionItem)

[FirstMinionItem SetDefaults](cs:./code/firstminion.cs#cs:m:ModDocProject.ModsSource.Modder入门.FirstMinionItem.SetDefaults())

### SetDefaults 核心属性

`Item.damage` 是伤害，`Item.mana` 是魔力消耗（必须设置）。

`Item.buffType = ModContent.BuffType<FirstMinionBuff>()` 关联 Buff。

`Item.shoot = ModContent.ProjectileType<FirstMinion>()` 关联投射物。

### 召唤物特有属性

`Item.noMelee = true` 表示这不是近战武器，防止近战加成影响。

`Item.DamageType = DamageClass.Summon` 声明伤害类型，必须设置以应用召唤物伤害加成。

`ItemID.Sets.StaffMinionSlotsRequired[Type] = 1f` 设置占用的召唤栏位数。

### 手柄支持

`ItemID.Sets.GamepadWholeScreenUseRange` 允许在屏幕任意位置召唤。

`ItemID.Sets.LockOnIgnoresCollision` 启用锁定瞄准模式，召唤物可穿墙攻击。

# 创建召唤物本体

## FirstMinion 类

`ModProjectile` 子类是召唤物的实际实体。

[FirstMinion 类定义](cs:./code/firstminion.cs#cs:t:ModDocProject.ModsSource.Modder入门.FirstMinion)

[FirstMinion SetStaticDefaults](cs:./code/firstminion.cs#cs:m:ModDocProject.ModsSource.Modder入门.FirstMinion.SetStaticDefaults())

[FirstMinion SetDefaults](cs:./code/firstminion.cs#cs:m:ModDocProject.ModsSource.Modder入门.FirstMinion.SetDefaults())

[FirstMinion AI 实现](cs:./code/firstminion.cs#cs:m:ModDocProject.ModsSource.Modder入门.FirstMinion.AI())

### SetStaticDefaults 配置

`Main.projFrames[Type]` 设置动画帧数。

`ProjectileID.Sets.MinionTargettingFeature` 启用右键锁定目标功能。

`Main.projPet[Type] = true` 标记为宠物/召唤物投射物。

`ProjectileID.Sets.MinionSacrificable` 允许 Q 键移除召唤物。

### SetDefaults 核心属性

`Projectile.tileCollide = false` 让召唤物可以穿墙。

`Projectile.friendly = true` 设置为友方投射物，会攻击敌人。

`Projectile.minion = true` 声明为召唤物，受召唤物系统管理。

`Projectile.DamageType = DamageClass.Summon` 确认伤害类型。

`Projectile.minionSlots = 1f` 占用 1 格召唤栏位。

`Projectile.penetrate = -1` 不限制穿透次数。

### CanCutTiles 方法

返回 `false` 表示召唤物不能破坏物块。

### MinionContactDamage 方法

返回 `true` 表示通过接触造成伤害，这是最简单的召唤物攻击方式。

### AI 逻辑

在 `AI` 方法中获取主人引用，检测玩家状态，使用 `Projectile.Center` 设置位置跟随，`Projectile.velocity` 控制移动。

帧动画使用 `Projectile.frameCounter` 计数器，每隔几帧切换一帧。
