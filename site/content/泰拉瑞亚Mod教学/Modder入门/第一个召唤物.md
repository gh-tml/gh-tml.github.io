# 前言

在泰拉瑞亚中，你一定用过星尘法杖召唤星尘之龙、用矮人法杖召唤小鬼……

这些跟随玩家、自动攻击敌人的存在叫做**召唤物（Minion）**！

{color:Mad}{在这一章，你将学会如何创建属于自己的召唤物！}

召唤物系统包含三个部分：
- `ModBuff` - 控制召唤物的存在状态
- `ModItem` - 作为召唤媒介的物品
- `ModProjectile` - 召唤物的本体

# 召唤物的组成部分

## 三者关系

```
玩家使用召唤物品
    ↓
添加 Buff
    ↓
触发投射物生成 → 召唤物出现
```

当玩家使用召唤物品时：
1. 消耗魔力
2. 给予玩家一个 Buff
3. Buff 触发投射物生成
4. 投射物就是召唤物本体

# 创建召唤物Buff

## FirstMinionBuff 类

[Buff 类定义](cs:./code/firstminion.cs#cs:t:ModDocProject.ModsSource.Modder入门.FirstMinionBuff)

```csharp
public class FirstMinionBuff : ModBuff
{
    public override void SetStaticDefaults()
    {
        // 不保存到存档
        Main.buffNoSave[Type] = true;

        // 不显示倒计时
        Main.buffNoTimeDisplay[Type] = true;
    }

    public override void Update(Player player, ref int buffIndex)
    {
        // 检测召唤物是否存在
        if (player.ownedProjectileCounts[ModContent.ProjectileType<FirstMinion>()] > 0)
        {
            player.buffTime[buffIndex] = 18000;
        }
        else
        {
            player.DelBuff(buffIndex);
            buffIndex--;
        }
    }
}
```

### 关键属性

| 属性 | 作用 |
|------|------|
| `buffNoSave` | 退出世界时不保存 |
| `buffNoTimeDisplay` | 不显示倒计时 |

# 创建召唤物品

## FirstMinionItem 类

[Item 类定义](cs:./code/firstminion.cs#cs:t:ModDocProject.ModsSource.Modder入门.FirstMinionItem)

### SetDefaults 核心属性

```csharp
Item.damage = 20;           // 伤害
Item.mana = 10;            // 魔力消耗
Item.buffType = ModContent.BuffType<FirstMinionBuff>(); // 关联Buff
Item.shoot = ModContent.ProjectileType<FirstMinion>(); // 关联投射物
```

### 召唤物特有属性

```csharp
Item.noMelee = true;                      // 不是近战武器
Item.DamageType = DamageClass.Summon;     // 召唤物伤害类型
ItemID.Sets.StaffMinionSlotsRequired[Type] = 1f; // 占用栏位
```

> [!IMPORTANT] DamageClass.Summon
>
> 必须设置 `DamageClass.Summon`，否则召唤物伤害会受到其他伤害加成的影响！

### 手柄支持

```csharp
ItemID.Sets.GamepadWholeScreenUseRange[Item.type] = true;
ItemID.Sets.LockOnIgnoresCollision[Item.type] = true;
```

这些设置让手柄玩家可以在屏幕任意位置召唤。

### AI 逻辑

[AI 方法](cs:./code/firstminion.cs#cs:m:ModDocProject.ModsSource.Modder入门.FirstMinion.AI())

```csharp
public override void AI()
{
    Player owner = Main.player[Projectile.owner];

    // 检测玩家状态
    if (!owner.dead && owner.active)
    {
        Projectile.timeLeft = 2;
    }

    // 跟随玩家
    Projectile.Center = owner.Center;
    Projectile.velocity = Vector2.Zero;

    // 攻击判定
    Projectile.friendly = true;

    // 动画
    Projectile.frameCounter++;
    if (Projectile.frameCounter >= 6)
    {
        Projectile.frameCounter = 0;
        Projectile.frame = (Projectile.frame + 1) % Main.projFrames[Projectile.type];
    }
}
```
